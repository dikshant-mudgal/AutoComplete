# AutoComplete

A simple C++ autocomplete project using a dictionary and trie data structure.

## 📂 Files

- `main.cpp` - Main logic and implementation
- `dictionary.txt` - Word list used for predictions

## 🚀 How to Run

1. Compile using a C++ compiler:
   ```bash
   g++ main.cpp -o autocomplete
2. Run the program:
./autocomplete


🧠 Features
Fast word prediction

Customizable dictionary

Lightweight CLI app

📌 Requirements
C++11 or higher
